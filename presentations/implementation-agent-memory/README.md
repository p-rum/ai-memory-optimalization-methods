# Paměť implementačního agenta

Česká prezentace: 23 hlavních snímků + 2 přílohy, 28 minut výkladu + 2 minuty diskuse.

- [PowerPoint](presentation.pptx) obsahuje editovatelné texty a tabulky, poznámky přednášejícího, časování a zdroje.
- [Text a poznámky](presentation.md) umožňují číst a upravovat celý obsah v GitHubu.
- [Strukturovaný obsah](slides.json) obsahuje data jednotlivých snímků. PPTX lze upravovat přímo v PowerPointu; JSON není automaticky synchronizován s PPTX.

## Obsah

SQL a symbolové indexy, vektorové hledání, znalostní grafy, kombinovaná paměť, tři příklady pro backend, srovnání Graphify, Aider, GraphRAG, Graphiti/Zep, Mem0, PostgreSQL/pgvector, Qdrant a LangGraph.

## Jak číst náklady

Výpočty jsou ilustrativní, nikoli měření produktů nebo aktuální ceník. Předpoklady: 3 USD / milion vstupních tokenů, 15 USD / milion výstupních tokenů, cache 0,30 USD / milion. Náklady zahrnují modelovou průběžnou údržbu paměti; fixní investice a provoz jsou uvedeny zvlášť. Výstup a úspěšnost držíme konstantní. Skutečný pilot musí měřit cenu za přijatou změnu včetně neúspěšných pokusů.

Primární zdroje ověřeny 13. 10. 2026. Publikované úspory jsou označeny jako tvrzení autorů či dodavatelů. Příklady neobsahují skutečný produkční kód nebo bankovní data.
